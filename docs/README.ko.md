# Vault in Vault

Obsidian 볼트 안의 개인 노트와 이미지를 암호화하고 필요할 때만 잠금을 해제하세요.

Vault in Vault가 제공하는 기능:

- **저장된 민감한 콘텐츠 보호.** 일기, 개인 기록, 업무 노트, 이미지를 암호화하여 복사, 백업 또는 동기화된 볼트에서 내용을 그대로 읽을 수 없게 합니다.
- **기존 파일 위치 유지.** 잠긴 파일은 원래 폴더에 남으며 표준 비밀번호 암호화 `.age` 파일로 저장됩니다.
- **잠금 해제 중에는 Obsidian을 평소처럼 사용.** 보호된 파일을 열고 비밀번호를 입력하면 기본 편집기, 이미지 미리보기, 링크, 검색을 계속 사용할 수 있습니다.
- **Obsidian을 벗어나지 않고 평문 다시 잠그기.** 마지막 탭을 닫을 때 한 파일을 암호화하거나, 노출된 모든 파일을 직접 잠그거나, 볼트가 비활성 상태인 뒤 자동으로 잠글 수 있습니다.
- **보호할 대상 선택.** 볼트 전체의 `.ageconfig` 정책으로 확장자를 지정하고 공개 폴더, 템플릿 또는 개별 파일을 제외할 수 있습니다.
- **익숙한 언어로 사용.** 인터페이스는 Obsidian의 언어 설정을 따르며 현재 영어, 중국어 간체, 중국어 번체, 일본어, 한국어를 지원합니다.

Vault in Vault는 파일 내용을 보호합니다. 파일 이름과 폴더 구조는 계속 표시됩니다.

> [!WARNING]
> 파일 잠금이 해제된 동안 평문은 디스크에 기록됩니다. 중요한 데이터에 사용하기 전에 백업하고 [보안 모델](#보안-모델)을 읽어 보세요. 이 프로젝트는 독립적인 보안 감사를 받지 않았습니다.

## Obsidian 커뮤니티 플러그인에서 설치

1. Obsidian에서 **설정 → 커뮤니티 플러그인**을 엽니다.
2. **탐색**을 선택하고 **Vault in Vault**를 검색합니다.
3. 플러그인을 선택한 뒤 **설치**, **활성화**를 차례로 선택합니다.

Vault in Vault는 현재 데스크톱에서만 사용할 수 있습니다. [Obsidian Community 등록 페이지](https://community.obsidian.md/plugins/vault-in-vault)에서도 확인할 수 있습니다.

## 빠른 둘러보기

### 암호화된 파일은 원래 폴더에 남습니다

암호화된 파일은 파일 탐색기에 **AGE**로 표시됩니다. 파일 이름과 폴더 구조는 보이지만 비밀번호 없이는 내용을 읽을 수 없습니다.

![Obsidian 파일 탐색기에 AGE로 표시된 암호화 파일](images/encrypted-files.png)

### 잠긴 파일을 클릭해 엽니다

파일을 읽거나 편집하려면 **복호화 후 열기**를 선택하세요.

![암호화된 Markdown 파일의 복호화 후 열기 버튼](images/decrypt-and-open.png)

비밀번호를 입력합니다. 원하는 경우 현재 Obsidian 세션 동안 메모리에 기억할 수 있으며 비밀번호는 디스크에 저장되지 않습니다.

![세션 동안 비밀번호 기억 옵션이 있는 비밀번호 입력 창](images/password-prompt.png)

복호화가 끝나면 노트가 Obsidian의 기본 편집기에서 열립니다. 잠금이 해제된 동안 Markdown, 이미지 미리보기, 링크, 검색, 호환되는 다른 플러그인을 평소처럼 사용할 수 있습니다.

### 탭을 닫을 때 암호화할 항목을 선택합니다

보호 대상 평문 파일이 열린 마지막 탭을 닫으면 방금 닫은 파일만 암호화하거나, 조건에 맞는 모든 평문 파일을 암호화하거나, 평문으로 유지할 수 있습니다. 다른 보호 대상 평문 탭이 열려 있는 동안에는 탭 하나를 닫아도 작업을 방해하지 않습니다.

![탭을 닫은 뒤 한 파일 또는 조건에 맞는 모든 파일을 암호화하는 확인 창](images/encrypt-on-close.png)

### 보호할 파일 형식을 선택합니다

설정 페이지에는 볼트 전체 잠금에 포함되는 파일 확장자가 표시됩니다. 설정은 항상 볼 수 있지만 실수로 변경하는 것을 막기 위해 수정 전 비밀번호 확인이 필요합니다.

![보호할 파일 형식과 임베드 이미지 설정](images/protected-file-settings.png)

### 암호화하지 않을 파일과 폴더를 지정합니다

공개 폴더, 템플릿 또는 개별 파일이 암호화나 비밀번호 확인 검사에 포함되지 않아야 한다면 `.ageconfig`의 `exclude`에 볼트 루트 기준 상대 경로를 추가하세요. 폴더를 지정하면 하위 항목 전체가 제외됩니다. 공유 정책을 사용하는 동안 현재 제외 항목은 설정 페이지에 읽기 전용으로 표시됩니다.

![ageconfig 공유 정책으로 관리되는 제외 파일 및 폴더](images/excluded-paths.png)

### 비밀번호를 사용할 수 있는 시간을 제한합니다

**세션 보안**에는 동시에 사용할 수 없는 두 가지 옵션이 있습니다. **비밀번호 자동 삭제**는 정해진 시간 뒤 캐시된 비밀번호만 삭제합니다. **볼트 비활성 시 자동 잠금**은 일정 시간 활동이 없으면 열린 Markdown 편집기를 저장하고, 조건에 맞는 평문 파일을 암호화하고, 보호에 성공한 탭을 닫은 뒤 비밀번호를 삭제합니다.

![비밀번호 자동 삭제 및 볼트 비활성 자동 잠금 설정](images/session-security.png)

리본 아이콘은 설정된 모드와 비밀번호 상태를 별도로 표시합니다.

![수동 잠금, 비밀번호 자동 삭제, 자동 유휴 잠금 및 비밀번호 상태 표시](images/security-mode-icons.png)

## 주요 기능

- 파일 탐색기에서 비밀번호로 암호화된 `.age` 파일을 직접 엽니다.
- Markdown과 이미지를 복호화해 평문을 원래 폴더에 되돌리고, 기본 편집, 미리보기, 링크, 검색 및 다른 플러그인을 사용할 수 있게 합니다.
- 보호 대상 평문이 열린 마지막 탭을 닫은 뒤 방금 닫은 파일, 조건에 맞는 모든 평문 파일 또는 암호화하지 않기를 선택할 수 있습니다.
- **지금 볼트 암호화 및 잠금** 명령과 리본 작업을 제공합니다.
- 사용자가 선택한 경우에만 현재 플러그인 세션의 메모리에 비밀번호를 캐시합니다.
- 리본 잠금 아래의 빨간색, 초록색, 노란색 표시등으로 비밀번호를 사용할 수 없음, 캐시됨, 만료 임박 상태를 보여 줍니다.
- 정해진 시간이 지난 뒤 비밀번호만 삭제하거나 현재 볼트에서 활동이 없는 상태가 지속된 뒤 자동으로 암호화하고 잠글 수 있습니다.
- 기본적으로 `.md`, `.avif`, `.bmp`, `.gif`, `.jpeg`, `.jpg`, `.png`, `.svg`, `.webp`를 보호하며 제외할 파일과 폴더도 지정할 수 있습니다.
- 하위 폴더를 유지하고 볼트 설정 폴더와 이미 `.age`로 끝나는 파일을 제외합니다.
- 원본 파일을 삭제하기 전에 새 평문 또는 암호문을 다시 읽어 검증합니다.
- Obsidian의 인터페이스 언어를 따르며 영어, 중국어 간체, 중국어 번체, 일본어, 한국어를 지원합니다.

## 파일 처리 과정

`notes/private.md.age`를 열고 **복호화 후 열기**를 선택하면 다음과 같이 처리됩니다.

```text
notes/private.md.age
    -> notes/private.md 복호화 및 검증
    -> notes/private.md.age 삭제
    -> 기본 편집기에서 notes/private.md 열기
```

보호 대상 평문이 열린 마지막 탭을 닫으면 암호화할 파일 목록이 접힌 상태로 표시됩니다. `.ageconfig`에 제외 경로가 있으면 건너뛸 파일과 폴더도 별도의 접힌 목록으로 표시됩니다. 다음 중 하나를 선택할 수 있습니다.

- **이 파일 암호화**
- **모두 암호화(N)**
- **평문으로 유지**

Obsidian이 일반 저장을 완료할 수 있도록 탭이 먼저 닫힙니다. 그다음 앱이 실행 중인 상태에서 암호화합니다. 비밀번호 입력을 취소하거나, 암호화 중 파일이 변경되거나, 검증에 실패하면 원본 평문 파일을 유지합니다.

**모두 암호화**를 선택하거나 **지금 볼트 암호화 및 잠금**을 실행하면 암호화 뒤 캐시된 세션 비밀번호가 삭제됩니다. 다음에 암호화 파일을 열 때 비밀번호를 다시 입력해야 합니다. 닫은 파일 하나만 암호화하면 세션 비밀번호를 삭제하지 않습니다.

플러그인은 앱 종료 훅에서 대화형 암호화를 시도하지 않습니다. Obsidian이 비동기 작업이 끝날 때까지 안정적으로 기다리지 않기 때문입니다. 종료하기 전에 보호 대상 탭을 닫거나 **지금 볼트 암호화 및 잠금**을 실행하세요.

## 비밀번호 동작

- 제외되지 않은 기존 `.age` 파일이 있으면 볼트 전체 암호화 전에 입력한 비밀번호를 그 파일로 확인합니다.
- `.age` 파일이 없으면 비밀번호를 두 번 입력해야 합니다.
- 기억하도록 선택한 비밀번호는 현재 플러그인 세션 동안 JavaScript 메모리에만 보관됩니다.
- 비밀번호는 `data.json`에 기록되지 않습니다.
- 비밀번호를 복구할 방법은 없습니다. 비밀번호를 잃으면 암호화된 파일을 복호화할 수 없습니다.

### 세션 보안 타이머

설정 페이지에는 동시에 사용할 수 없는 두 타이머가 있습니다. 둘 다 기본값은 끄기입니다.

- **비밀번호 자동 삭제**: 비밀번호가 메모리에 들어간 시점부터 정해진 시간이 지나면 캐시를 삭제합니다. 사용자 활동으로 기한이 연장되지 않으며 평문 파일은 그대로 유지됩니다.
- **볼트 비활성 시 자동 잠금**: 현재 볼트에서 키보드, 포인터, 터치, 스크롤, 편집기 또는 탭 활동이 있을 때마다 타이머를 다시 시작합니다. 기한이 되면 열린 Markdown 편집기가 저장될 때까지 기다리고, 조건에 맞으며 제외되지 않은 모든 평문 파일을 암호화하고, 보호에 성공한 탭을 닫은 뒤 추가 확인 없이 비밀번호를 삭제합니다.

리본에서는 비밀번호 자동 삭제를 '열쇠 + 시계', 자동 유휴 잠금을 '자물쇠 + 원형 화살표'로 표시합니다. 두 타이머가 모두 꺼져 있으면 일반 자물쇠를 표시합니다. 오른쪽 위 배지는 설정 모드를 나타내고 아래쪽 빨간색, 초록색, 노란색 표시등은 비밀번호 사용 가능 여부와 기한 임박 상태를 나타냅니다. 설정 페이지에서도 같은 아이콘을 사용합니다.

자동 유휴 잠금에는 비밀번호가 계속 캐시되어 있어야 합니다. 이 모드를 켜면 비밀번호 창의 **자동 잠금까지 기억**이 항상 활성화됩니다. 다시 시작한 뒤 비밀번호가 복원되지 않으므로 다시 입력하기 전까지 자동 잠금은 대기 상태가 아닙니다.

여기서 유휴 상태는 플러그인이 현재 볼트의 Obsidian 기본 창과 팝아웃 창에서 활동을 감지하지 못한 상태를 뜻합니다. 운영 체제 전체의 유휴 상태를 감지하는 것은 아닙니다. 다른 앱으로 전환해도 카운트다운은 계속됩니다. 백그라운드 동기화와 파일 수정 시간은 타이머를 초기화하지 않습니다. 컴퓨터가 잠자기 상태가 되거나 Obsidian이 일시 중단되면 복귀하는 즉시 기한을 다시 확인합니다.

## 암호화 범위 설정과 `.ageconfig`

파일 형식은 **설정 → Vault in Vault → 보호할 파일 형식**에서 지정합니다. 보안 타이머도 같은 설정 페이지에 있습니다. `.ageconfig`가 없으면 확장자, 제외 경로, 타이머 설정이 현재 볼트의 플러그인 폴더에 있는 `data.json`에 저장됩니다. 비밀번호는 저장되지 않습니다. 보호 정책을 편집하려면 볼트 비밀번호를 확인해야 하지만 타이머는 언제든지 조정할 수 있습니다.

Obsidian 플러그인과 Go 명령줄 도구에서 같은 정책을 공유하려면 볼트 루트에 `.ageconfig`를 만드세요.

```json
{
  "extensions": [".md", ".png", ".jpg"],
  "exclude": ["Public", "Templates/daily.md", "attachments/shared"]
}
```

- `extensions`는 보호할 평문 파일 형식을 지정합니다. 생략하면 Markdown과 일반 이미지 형식에 대한 내장 기본값을 사용합니다. 명시하는 경우 빈 배열일 수 없습니다.
- `exclude`에는 볼트 루트 기준 상대 파일 또는 폴더 경로를 지정합니다. 폴더를 지정하면 하위 항목 전체를 건너뜁니다.
- 경로는 대소문자를 구분합니다. `*`, `?`와 같은 와일드카드, 절대 경로, `..`는 사용할 수 없습니다.
- `.ageconfig`가 있으면 `data.json`보다 우선합니다. 공유 확장자와 제외 항목은 설정 페이지에 읽기 전용으로 표시됩니다. 설정 페이지에서 운영 체제의 기본 편집기로 파일을 열거나 Finder/파일 관리자에서 표시할 수 있습니다. 저장한 뒤 **.ageconfig 다시 불러오기**를 선택하세요.
- 설정이 올바르지 않으면 더 넓은 기본 정책으로 조용히 돌아가지 않고 암호화를 중단합니다. `.ageconfig`와 `data.json`에는 비밀번호가 저장되지 않습니다.

제외 경로만 설정하려면 다음과 같이 작성할 수 있습니다.

```json
{
  "exclude": ["Public", "Templates"]
}
```

## 보안 모델

- 잠금 해제된 콘텐츠는 디스크의 일반 평문 파일입니다.
- 메타데이터 캐시, 검색 색인, File Recovery, 다른 플러그인, 동기화 도구 및 시스템 백업에 평문이 남을 수 있습니다.
- 충돌, 강제 종료, 전원 손실 또는 앱을 바로 종료하면 평문 파일이 남을 수 있습니다.
- JavaScript는 비밀번호 문자열이 프로세스 메모리에서 즉시 제거되는 것을 보장할 수 없습니다.
- 플러그인은 대체 파일을 만들고 다시 읽어 암호학적으로 검증한 뒤에만 원본을 삭제합니다. 평문을 휴지통으로 옮기면 암호화되지 않은 사본이 남으므로 이 전환 과정에서는 Obsidian의 일반 휴지통 동작을 사용하지 않습니다.
- 파일 잠금이 해제된 동안에는 실행 중인 Obsidian 프로세스나 로컬 파일을 읽을 수 있는 다른 소프트웨어 또는 사용자로부터 데이터를 보호할 수 없습니다.

이 플러그인에는 원격 측정, 광고, 계정 요구 사항 또는 원격 서비스가 없으며 현재 볼트 밖의 파일에 접근하지 않습니다. 일반적인 사용은 완전히 오프라인입니다.

## 수동 설치

로컬 개발 빌드를 설치하려면 Node.js 20 이상이 필요합니다.

```bash
npm ci
npm run check
npm run install:vault -- "/your/vault/absolute/path"
```

마지막 명령은 `main.js`, `manifest.json`, `styles.css`를 다음 위치로 복사합니다.

```text
<Vault>/.obsidian/plugins/vault-in-vault/
```

이 세 파일을 직접 복사해도 됩니다. Obsidian을 다시 시작하거나 다시 불러온 뒤 **설정 → 커뮤니티 플러그인**에서 **Vault in Vault**를 활성화하세요.

이전 개발 버전을 `fileencrypt-age-viewer` ID로 설치했다면 `vault-in-vault`를 활성화하기 전에 비활성화하세요. 새 ID는 별도의 플러그인으로 처리됩니다. 확장자 설정을 유지하려는 경우에만 이전 폴더의 `data.json`을 새 플러그인 폴더로 복사하세요. 비밀번호는 포함되어 있지 않습니다.

## 개발 및 릴리스

```bash
npm ci
npm run dev
npm test
npm run check
```

`npm version patch`, `npm version minor`, `npm version major` 중 하나로 버전을 올립니다. 스크립트가 `package.json`, `manifest.json`, `versions.json`을 동기화합니다. manifest 버전과 정확히 일치하고 `v` 접두사가 없는 태그를 푸시하면 GitHub Actions가 빌드하고 초안 Release를 만듭니다. 별도의 Release를 직접 만들 필요는 없습니다.

초안을 열어 release notes를 작성하고 `main.js`, `manifest.json`, `styles.css`가 각각 다운로드할 수 있는 세 개의 첨부 파일인지 확인한 뒤 **Publish release**를 선택합니다. 초안 상태에서는 Obsidian이 설치할 수 없으며 Community 제출에도 사용할 수 없습니다.

## 호환성

Vault in Vault 0.8.0 이상은 Obsidian 1.8.7 이상이 필요합니다. 이를 통해 플러그인이 Obsidian에서 선택한 인터페이스 언어를 따를 수 있습니다.
